# Fixtures

Small invented files that tests read instead of the maintainer's real save or the real game install. Everything here is synthetic: it was built by `tools/fixture-builder` (step 3) or written by hand, and holds no real hunter name or ID and no Capcom data.

The repo hygiene test fails on any file under `fixtures/` whose name is not listed in this file as synthetic, and on any save, pack or dump anywhere else.
