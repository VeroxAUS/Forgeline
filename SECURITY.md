# Security policy

Forgeline is pre-alpha and has no release yet. Once it does, only the latest release is supported.

## Reporting a problem

Please report security problems **privately**, not in a public issue:

1. Go to the [Security tab](https://github.com/VeroxAUS/Forgeline/security) of this repo.
2. Choose **Report a vulnerability** (GitHub private vulnerability reporting).

Include what you found, how to reproduce it, and the app version. Do not attach save files or anything with your hunter ID.

Examples that count: the app writing to a save, the install or Steam folders; the app sending data off your machine; a crafted save or data file that crashes or runs code in the reader or extractor; a secret committed to the repo.

You can expect a first reply within a few days. This is a volunteer project, so there is no bug bounty.
